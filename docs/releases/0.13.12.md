# Cursed Workshop 0.13.12

Unofficial community tool for Call to Arms - Gates of Hell: Ostfront Dynamic Conquest.

## New

- Dismantle owned vehicles into chassis, separable turrets, weapon mounts and detachable guns. Components go to the Depot and crew returns to reserve. Integrated weapons stay with their mounting component; ammunition is not duplicated.
- Depot cards distinguish component types and provide combined type, nation and source filters. Build from Depot components without consuming another complete vehicle; assign reserve veterans to the new vehicle's empty crew seats in game.
- Draft autosave and recovery for unfinished designs. Recovery checks the original campaign before restoring and never builds a vehicle or changes your save automatically.
- Hide, isolate or lock pieces in the editor, with a searchable viewport-piece list. These controls only change the editor view.
- Configurable keyboard shortcuts, movement/rotation snapping and a modifier for fine adjustments, available in Settings.
- Compact Global / Local axis buttons beside Rotate, shared by the transform controls. Added Mirror X / Y / Z for editable pieces.
- Vehicle sight editing: move and rotate the invisible sight, choose which part it follows, preview its viewpoint and restore the original sight. The game retains its native optics and zoom; the editor preview shows position and direction.
- Single-shot weapons expose magazine capacity 1. Increase it to add a magazine, or resize an existing magazine. Fire rate and full-magazine reload time remain separate settings.
- Russian interface, including Settings, tooltips and progress messages. The language is detected from Windows until you choose another and is remembered across restarts.
- Settings shows the editor's disk-cache size and offers Clear cache. Only regenerable editor data is removed; vehicles, campaigns, backups, drafts and settings are preserved. The next load may take longer. This does not clear the game's cache or guarantee better game performance.

## Resizable armor

- Added triangular plates, circular plates and hollow cylinders, plus adjustable circular openings with matching collision geometry.
- Edit individual profile points in local coordinates using viewport handles. Shift-click selects multiple points to move together, including points on circular and cylindrical profiles.
- Cylinders and openings use continuous surfaces without internal walls between segments. Corner movement follows reflected attachment frames correctly.
- Duplicated armor stays in preview until Add armor is pressed. Placement controls now appear higher in the armor panel.
- Added British, Finnish, German, American, Soviet and French finishes and solid colors. Each piece remembers its finish, with matching editor/game textures and cylindrical wrapping.
- Removed the two German bolted finishes from new choices. Saved vehicles using them remain editable and rebuildable.

## Improvements

- Texture-quality settings: 256 px, 512 px, 2048 px or original resolution. Models already use their highest available detail. Changing texture quality refreshes visible materials and releases the previous textures.
- RAM-saving mode skips background catalog preparation and loads catalogs when first needed. Temporary model-reading resources are released sooner.
- Restored numeric-field arrows and widened fields so values remain readable. Ordinary fields step by one and retain typed fractional values.
- Error dialogs separate recovery suggestions from technical details. Improved operation progress and cancellation for supported tasks.
- Unavailable dropdown choices show why they cannot be selected.
- Completed missing English, Spanish and Simplified Chinese labels, paint names and multiline confirmations. Game resource identifiers and player-created names stay unchanged; support reports remain in English.

## Fixes

- Fixed the MACE T91 rocket launcher and other weapons being rejected when the weapon and vehicle use different forms of the same ammunition-family name. Unrelated ammunition families remain rejected.
- Fixed native ammunition inheritance using space-separated item names, and unresolved commander-optics references blocking otherwise valid gun replacements.
- Gun replacement clears edited attributes belonging to the previous weapon. Native penetration tables with distances stored out of order can be edited and built, including MACE anti-tank rifles.
- Fixed Kangaroo Mk.I / Mk.II crew recognition when opening them or using them as chassis. Ordinary passenger seats remain passengers.
- Additional turrets can use further numbered crew roles instead of exhausting the native examples and rejecting a fourth turret.
- Fixed the camera moving while dragging transform arrows, armor points or weapon-angle handles, including residual camera damping.
- Fixed armor attachment checks for joints created during assembly. Creative armor placement remains available when Conquest registration fails, and procedural armor can be created or reopened without scanning the native armor catalog.
- Fixed invalid gear-ratio ordering caused by edited vehicle speeds. Previously built vehicles need Update vehicles to receive the export correction.
- Diagnostic ZIPs include generated destruction-state definitions and models, improving reports for mod-loading and campaign crashes.

## Work in progress

Back up your campaign before using the tool. In-game acceptance remains pending for several new features, including sight behavior, magazine changes, dismantled builds and the T91 launcher's firing behavior. Further Linux/Proton confirmation is still needed. The separate unexpected-token crash reported in a destroyed-vehicle definition remains unconfirmed.

## Install or update

Download `CursedWorkshop-0.13.12-win64.zip`, extract the entire archive and run
`CursedWorkshop/CursedWorkshop.exe`. Keep the `_internal` folder beside the executable. Players do not need
Python or Node.js. The Microsoft Edge WebView2 Runtime is required for the desktop window; `--browser` uses
the default browser instead. See [Microsoft's WebView2 Runtime download](https://developer.microsoft.com/microsoft-edge/webview2/).

Close the old editor before updating. Your built vehicles stay in the game's `mods/modular_workshop` folder
and your editor data in `%LOCALAPPDATA%/ModularWorkshop`. Keep campaign and editor-data backups.
Use Update vehicles to apply export fixes to vehicles built before this release.

The ZIP includes installation instructions, the user guide and third-party notices.

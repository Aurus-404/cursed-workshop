# Cursed Workshop 0.13.12

Unofficial community tool for Call to Arms - Gates of Hell: Ostfront Dynamic Conquest.

## New

### Dismantling and a better Depot

- **Dismantle vehicles for parts.** Choose Dismantle and select a vehicle you own to see what can be recovered before confirming. Its chassis, removable turrets and guns go to the Depot, while its crew returns to reserve. Weapons that cannot be removed separately stay with their original part.
- **Find the right part more easily.** Depot cards now clearly distinguish chassis, turrets, gun mounts and individual guns. Filter by part type, nation and source, and combine those filters.
- **Build using saved parts.** You can assemble a vehicle entirely from Depot components without sacrificing another complete vehicle. Its crew seats start empty so you can assign reserve veterans in game. Dismantling does not create extra ammunition.

### More control over placement

- **Global and Local axes**, beside Rotate. Choose Global to move or rotate along the editor's axes, or Local to follow the selected part's own direction. The setting also works with crew and accessories.
- **Mirror X / Y / Z.** Flip an editable piece across the chosen axis, including armor and weapons.
- **Move the vehicle's sight.** Under Vehicle sight, reposition and rotate the invisible aiming point and choose which part it follows. For example, attach it to the turret so it turns with the turret. Preview sight lets you look from that position to check the view; Restore original sight undoes your changes. The game's original zoom and optics are kept.
- **Change magazine size.** Weapon attributes now lets you give a single-shot weapon a magazine or enlarge an existing one. Set rounds per magazine to 1 for single-shot behavior, or increase it for more shots before reloading. Fire rate controls the delay between shots; reload time applies when the magazine is empty.

### Resizable armor

- Added **triangular plates, circular plates and hollow cylinders**, alongside rectangular plates.
- **Edit the shape point by point.** Use Edit corners and drag a point to reshape the piece, or enter its local coordinates. This also works with triangular plates and the outlines of circular plates and cylinders.
- **Shift-click selects several points** so you can move them together.
- Added **circular openings** with adjustable position and diameter. The opening also exists in the armor used by the game.
- Cylinders and openings no longer have unwanted internal walls between their sections. Point movement also works correctly on mirrored attachments.
- Duplicating armor now creates a preview: it is not placed until you press **Add armor**.
- Added **British, Finnish, German, American, Soviet and French finishes**, plus solid colors and pink. Choose a finish for each piece; it is saved with the design and used in the editor and the game.
- Moved the armor movement controls higher in the panel, below Choose extra armor.
- Removed the two German bolted finishes from new choices. Existing vehicles using them can still be edited and rebuilt.

### Editor convenience

- **Automatic draft saving and recovery.** Recover an unfinished design after reopening the editor. Recovery checks that the campaign still matches and does not build or change your save automatically.
- **Hide, isolate and lock pieces.** Use the Pieces list to find parts, hide things that obstruct your view or lock pieces you do not want to move accidentally. This only affects the editor view.
- **Configurable shortcuts and precise movement.** Settings lets you change keyboard shortcuts, choose fixed movement and rotation steps, and configure fine adjustments. Snapping also works with crew and armor points.
- **Numeric arrows are back**, with wider fields so you can read the number and still increase or decrease it using the arrows. You can still enter fractional values.
- **Russian interface**, with automatic Windows-language detection and a remembered language choice. Completed missing English, Spanish and Simplified Chinese translations, including paint names and confirmation messages.
- **Clearer errors and progress.** Error messages suggest what to try next, with technical details available separately. Progress messages identify the current task, and supported tasks can be cancelled.
- Unavailable options in searchable lists now explain why they cannot be selected.

### Memory, textures and cache

- **Texture quality in Settings:** choose 256 px, 512 px, 2048 px or the original resolution. Higher settings show sharper textures but use more memory and may take longer to load. Models already use their highest available detail.
- **RAM-saving mode:** catalogs load when you open the relevant tool instead of being prepared in the background. The editor also releases temporary model data sooner.
- **Clear cache in Settings:** see how much space the editor's cache uses and remove data it can recreate. Vehicles, campaigns, backups, drafts and settings are kept. The next load may take longer. This clears the editor's disk cache, not the game's, and is not a guaranteed fix for game lag.

## Fixes

- The **MACE T91 rocket launcher** and other weapons using the same ammunition format can be mounted again. The editor was incorrectly reporting that their ammunition was incompatible.
- Fixed other cases where the editor could not find ammunition definitions even though the game could use them.
- Fixed some vehicles showing no replaceable guns because a commander sight was being mistaken for a broken weapon.
- Replacing a gun no longer carries over edited settings from the previous gun. Fixed editing penetration tables on some weapons, including MACE anti-tank rifles.
- **Kangaroo Mk.I / Mk.II** can be opened and used as chassis correctly; passenger seats are no longer confused with required crew positions.
- Fixed commander/gunner assignment errors when adding several extra turrets, including a fourth turret.
- Dragging movement arrows, armor points or weapon-angle handles no longer moves the camera at the same time.
- Fixed armor becoming unavailable in Creative when the selected vehicle could not be listed in Conquest. Creating or reopening resizable armor no longer requires loading the entire armor catalog first.
- Fixed some valid armor attachment points being rejected after other accessories were added.
- Fixed a campaign-loading crash caused by the vehicle's gear settings after changing its speed. Use **Update vehicles** for vehicles built before this fix.
- Diagnostic ZIPs now include more of the files needed to investigate crashes involving destroyed vehicles.

## Work in progress

Back up your campaign before using the tool. Several new features still need confirmation in actual battles, including sight behavior, magazine changes, vehicles assembled from dismantled parts and the T91 launcher's firing behavior. Further Linux/Proton confirmation is also needed. The separate unexpected-token crash reported for a destroyed vehicle remains under investigation.

## Install or update

Download `CursedWorkshop-0.13.12-win64.zip`, extract the entire archive and run
`CursedWorkshop/CursedWorkshop.exe`. Keep the `_internal` folder beside the executable. Players do not need
Python or Node.js. The Microsoft Edge WebView2 Runtime is required for the desktop window; `--browser` uses
the default browser instead. See [Microsoft's WebView2 Runtime download](https://developer.microsoft.com/microsoft-edge/webview2/).

Close the old editor before updating. Your built vehicles stay in the game's `mods/modular_workshop` folder
and your editor data in `%LOCALAPPDATA%/ModularWorkshop`. Keep campaign and editor-data backups.
Use **Update vehicles** to apply these fixes to vehicles built before this release.

The ZIP includes installation instructions, the user guide and third-party notices.

# Cursed Workshop 0.10.11

Work in progress. Unofficial community tool for Call to Arms - Gates of Hell: Ostfront Dynamic Conquest.

## Fixes

- Vehicles fitted with a gun that has limited traverse now get the same chassis aiming setup as native casemates. The chassis root is included in the aiming chain, so reaching the gun's azimuth limit can pass the turn to the driver. Applies to assembled, edited and rearmed vehicles, including field guns mounted on tank hulls.
- Fixed the campaign crash "Zero speed in ik-bone" when a saved design used a very low traverse speed. The earlier 0.5 degrees per second minimum was still too low. Turret and gun speed overrides now have a minimum of 1 degree per second, and older recipes are adjusted when rebuilt.

Press "Update vehicles" once to apply these fixes to vehicles you already built, then restart the game before testing them.

## Install or update

Download `CursedWorkshop-0.10.11-win64.zip`, extract the entire archive and run
`CursedWorkshop/CursedWorkshop.exe`. Keep the `_internal` folder beside the executable. Players do not need
Python or Node.js. The Microsoft Edge WebView2 Runtime is required for the desktop window; `--browser` uses
the default browser instead. See [Microsoft's WebView2 Runtime download](https://developer.microsoft.com/microsoft-edge/webview2/).

Close the old editor before updating. Your built vehicles stay in the game's `mods/modular_workshop` folder
and your editor data in `%LOCALAPPDATA%/ModularWorkshop`. Keep campaign and editor-data backups.

The ZIP includes installation instructions, the user guide and third-party notices.

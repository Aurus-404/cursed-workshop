# Cursed Workshop 0.9.10

Work in progress. Unofficial community tool for Call to Arms - Gates of Hell: Ostfront Dynamic Conquest.

## New

- Traverse speed: Turret and gun limits now shows how fast each turret and gun turns, in degrees per second,
  and lets you change it. Empty keeps the original vehicle's speed.
- Passenger and commander machine guns from your active mods can be mounted, such as MACE's Japanese machine
  guns (Type 92, Type 96, Type 97, Type 99, Vickers and more). DLC weapons still need their DLC.

## Fixes

- Flamethrowers can replace a gun (the Churchill Crocodile's flame projector on a hull MG mount, and others):
  their fuel was not recognised.
- A StuG III A with a StuG III G superstructure, and any vehicle whose new part left behind an MG mount,
  no longer crashes the game when the campaign opens.
- Putting a gun on a secondary mount (a 2 cm in the hull MG slot) no longer gives the main gun its muzzle flash
  and sound.

Press "Update vehicles" once to apply these fixes to vehicles you already built.

## Install or update

Download `CursedWorkshop-0.9.10-win64.zip`, extract the entire archive and run
`CursedWorkshop/CursedWorkshop.exe`. Keep the `_internal` folder beside the executable. Players do not need
Python or Node.js. The Microsoft Edge WebView2 Runtime is required for the desktop window; `--browser` uses
the default browser instead. See [Microsoft's WebView2 Runtime download](https://developer.microsoft.com/microsoft-edge/webview2/).

Close the old editor before updating. Your built vehicles stay in the game's `mods/modular_workshop` folder
and your editor data in `%LOCALAPPDATA%/ModularWorkshop`. Keep campaign and editor-data backups.

The ZIP includes installation instructions, the user guide and third-party notices.

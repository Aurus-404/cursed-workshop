# Cursed Workshop 0.8.10

Work in progress. Unofficial community tool for Call to Arms - Gates of Hell: Ostfront Dynamic Conquest.

- The editor opens in its own window again when it is downloaded as a ZIP. Windows marks files extracted
  from a downloaded archive as coming from the internet, and that mark stopped the window engine from
  loading, so 0.8.9 fell back to the browser. The editor now clears that mark from its own files.
- Adjusting a vehicle no longer freezes the 3D view. Background previews show in a small bar under the
  model, so you can keep moving parts while they update. Building and other operations still wait.
- Previews no longer wait minutes after every build. The editor's whole-game lists (extra armour, supply
  cargo, mounted weapons, crew poses) were read again each time a vehicle was built; they are now kept
  until the game or your other mods change.

## Install or update

Download `CursedWorkshop-0.8.10-win64.zip`, extract the entire archive and run
`CursedWorkshop/CursedWorkshop.exe`. Keep the `_internal` folder beside the executable. Players do not need
Python or Node.js. The Microsoft Edge WebView2 Runtime is required for the desktop window; `--browser` uses
the default browser instead. See [Microsoft's WebView2 Runtime download](https://developer.microsoft.com/microsoft-edge/webview2/).

Close the old editor before updating. Your built vehicles stay in the game's `mods/modular_workshop` folder
and your editor data in `%LOCALAPPDATA%/ModularWorkshop`. Keep campaign and editor-data backups.

The ZIP includes installation instructions, the user guide and third-party notices.

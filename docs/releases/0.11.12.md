# Cursed Workshop 0.11.12 Hotfix

Unofficial community tool for Call to Arms - Gates of Hell: Ostfront Dynamic Conquest.

## New

- Creative tab (was Catalog): click any vehicle in the game (tanks, AT, AA, APCs, trucks, cars…) and use it as chassis or turret, as set in "On click, use as". There is no separate checkbox. Opening the tab keeps your current selection, so you can take a chassis from your campaign and a turret from here.
- Shop: "Remove from the list" button. It asks first, then the vehicle stops being sold and leaves the list for good. Vehicles you already have in your campaigns are kept.

## Fixes

- Moving something no longer shows the full loading screen; background work shows as a small strip again (0.11.11 shipped with some styles missing).
- Moving extra armour, smoke launchers, towing or demolition charges no longer rebuilds the preview or rechecks compatibility. On vehicles with many pieces this went from minutes to instant.
- Building and checking compatibility is about twice as fast on vehicles with many weapons.
- The shop no longer fails when one of your vehicles was built with mods that are not active now (for example a MACE turret on a Horten's stack). You can take it off sale or off the list; the list marks it, and selling it explains why it cannot.
- Opening the shop without a campaign no longer fills the log with icon errors.
- Linux and Steam Deck: workshop.log records memory use while the tool works, to track down the crash when applying a gun or turret change under Proton.

## Install or update

Download `CursedWorkshop-0.11.12-win64.zip`, extract the entire archive and run
`CursedWorkshop/CursedWorkshop.exe`. Keep the `_internal` folder beside the executable. Players do not need
Python or Node.js. The Microsoft Edge WebView2 Runtime is required for the desktop window; `--browser` uses
the default browser instead. See [Microsoft's WebView2 Runtime download](https://developer.microsoft.com/microsoft-edge/webview2/).

Close the old editor before updating. Your built vehicles stay in the game's `mods/modular_workshop` folder
and your editor data in `%LOCALAPPDATA%/ModularWorkshop`. Keep campaign and editor-data backups.

The ZIP includes installation instructions, the user guide and third-party notices.

# Cursed Workshop 0.8.9

Work in progress. Unofficial community tool for Call to Arms - Gates of Hell: Ostfront Dynamic Conquest.

- First official GitHub distribution, with public application source and a portable Windows x64 download.
- Update vehicles rebuilds a vehicle even when its crew capacity changes, instead of retaining an older
  version that may fail when the campaign loads. Surplus crew is moved to a registered reserve squad when
  the campaign is opened in the editor, with a save backup.
- Includes the current armour preview correction and vehicle icons in the Conquest shop.
- All existing editing features and the English, Spanish and Simplified Chinese interface are retained.

## Install or update

Download `CursedWorkshop-0.8.9-win64.zip`, extract the entire archive and run
`CursedWorkshop/CursedWorkshop.exe`. Keep the `_internal` folder beside the executable. Players do not need
Python or Node.js. The Microsoft Edge WebView2 Runtime is required for the desktop window; `--browser` uses
the default browser instead. See [Microsoft's WebView2 Runtime download](https://developer.microsoft.com/microsoft-edge/webview2/).

Select the installed game folder in Settings if automatic Steam-library detection does not find it.
The retired Steam Workshop item is not required. Existing editor data remains in
`%LOCALAPPDATA%/ModularWorkshop`; generated vehicles remain in the game's `mods/modular_workshop` folder.
Close the old editor before updating. Keep campaign and editor-data backups.

The ZIP includes installation instructions, the user guide, third-party notices, build identity and a file
manifest. Compare its SHA-256 with `SHA256SUMS.txt` on the release before running it.

## Validation limits

Publication requires automated Python/frontend tests, a build/source identity check, a package-content audit
and launching the ZIP's extracted executable with isolated synthetic resources. The release manifest records
the actual completed checks. This does not certify every game/DLC/MACE combination or replace a player's
in-game battle test. Manual battle acceptance of this GitHub package is **NOT TESTED**.

After Workshop security-policy changes and the removal of our item, distribution has moved to GitHub.
The developer's [official announcement](https://store.steampowered.com/news/app/400750/view/715668461242548712)
provides context. The specific reason for removal has not been confirmed; this release does not claim that
all independent file editors are prohibited or that removal was unjustified.
